# Rodriguez Habit Cup

Freddy and Maria's daily fitness and nutrition tracker. A static page on GitHub Pages that reads and writes through a Google Apps Script backend, with all data in a Google Sheet on Maria's personal Google Drive.

- Each person opens their own personal link (`?u=<code>`). The codes are not in this repo.
- The backend code and the codes live in the private family brain repo (`.claude/skills/fitness-hub/`).
- Tip for phones: open your link, then Share, Add to Home Screen. It opens like an app and remembers who you are.
